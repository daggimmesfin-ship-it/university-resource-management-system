# 🎓 University Resource Management System

A Python-based console application designed to manage university learning resources. The system allows users to add, view, search, and delete resources while saving data in a JSON file for future use.

## ✨ Features

- ➕ Add new university resources
- 📚 View all available resources
- 🔍 Search for a specific resource
- 🗑️ Delete resources
- 💾 Save resource data using JSON
- 🔄 Load previously saved data when the program runs again
- 🖥️ Simple, menu-driven console interface

## 🛠️ Technologies Used

- **Python** — Application development
- **JSON** — Data storage and persistence
